# JHIC V2 - Home, Auth, UMKM & Privacy

React + Vite implementation for Jelajah Bojonegoro.

## Halaman
- Home sebelum login
- Login
- Register
- Verifikasi
- Home setelah login
- Direktori UMKM
- Detail produk UMKM
- Privacy Policy

## Jalankan
```bash
npm install
npm run dev
```

## Struktur utama
```text
src/
├── assets/
├── components/
│   ├── AuthBrand.jsx
│   ├── AuthField.jsx
│   ├── Icon.jsx
│   └── TravelHomeLayout.jsx
├── pages/
│   ├── Home.jsx
│   ├── HomeLoggedIn.jsx
│   ├── Login.jsx
│   ├── Register.jsx
│   ├── Verification.jsx
│   ├── UMKM.jsx
│   ├── ProductDetail.jsx
│   └── PrivacyPolicy.jsx
├── App.jsx
├── App.css
├── data.js
└── index.css
```

Desain UMKM, detail produk, dan Privacy Policy mengikuti referensi JHIC-v2 yang diberikan, sementara komponen tetap dibuat sebagai React code agar dapat diedit dan dikembangkan.
